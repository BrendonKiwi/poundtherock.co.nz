# Pound the Rock Limited website

Simple static company website for poundtherock.co.nz.

## Pages

- `/` — Company homepage
- `/space-times-tables/` — Space Times Tables product page
- `/support/` — Product/company support
- `/privacy/` — Privacy policy

## Hosting plan

GitHub Pages, with the existing `poundtherock.co.nz` domain remaining registered and DNS-managed through 1st Domains.

Do not change the current email-related DNS records when connecting the website. The existing `brendon@poundtherock.co.nz` forwarding setup should remain intact.
